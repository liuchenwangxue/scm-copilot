## 五、面试题 0.5h：指标体系全貌口述（反 Demo 化四原则）

> **方法论（面试可讲）**：每个指标三件套——值 + 测量方法 + 证据文件；未达项四件套——实测 + 根因 + 降级路径 + 改进路线。

**15 项怎么测的（抽查口述）**：
1. **NL2SQL 0.970 怎么来的**：100 条三层评测集（单40/join40/聚合20）→ gold/gen SQL 各执行 → **结果集规范化比对**（类型归一+排序键整行+列子集匹配）——不是 SQL 字符串比对。
2. **20/20 攻击怎么来的**：20 条攻击（堆叠/写/伪装嵌写/危险函数/FOR UPDATE/越权表）→ sqlglot 四道闸确定性拦截 + `nl2sql_ro` 只读账号兜底（ERROR 1142）。
3. **40 并发 100% / P95 2087ms 怎么来的**：`load_test.py` 混合路径打 nginx → 200/200 成功 + 5xx=0；P95 超限根因 AsyncMySaver 单连接串行——**正式口径取 30 并发**。
4. **零重复 30/30 怎么来的**：`scheduler_job_runs` 按 (job, 分钟窗口) 聚合，`status != skipped` 恰 1 条；leader 锁互斥 + 幂等键兜底。
5. **SDK 13/13 怎么来的**：干净环境 pip 装 → 真实 HTTPS 平台三接口 + 429 + 吊销 401。

**反 Demo 化四原则**：① 数字有测量方法（不是截图）；② 数字可复现（命令即证据）；③ 未达如实标注（40 并发 P95 / coverage / 夜间 7 晚）；④ 每个未达有根因 + 改进路线。
