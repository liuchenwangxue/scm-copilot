## 第一幕 · 对话查数（0:20–2:30）≈ 2min

> **画面**：对话页（`/ui/` Tab 1）

操作：
1. 输入"**近 30 天华东区域的延迟发货 TOP5 供应商是哪些？**" → 回车
2. SSE 流式打字出现（口播："这是流式输出"）
3. 结果**表格**渲染（`gr.Dataframe`）出现（口播："自然语言转 SQL，结果直接出表格"）
4. 展开 **SQL 折叠面板**（`gr.Accordion("查看 SQL")`）（口播："SQL 100% 透出，可审计、可纠错——不是黑盒"）
5. 展开**引用/洞察**（口播："洞察数字来自结果集，有数字溯源校验"）

**金句（安全纵深 30 秒）**：
"SQL 是模型生成的，直接执行有注入风险。我做了两层防御：第一层，生成后过 **sqlglot AST 四道闸**——单语句限制、只允许 SELECT、子句级拦截写操作、危险函数黑名单；第二层，执行用 **只读账号**，就算校验有未知绕过，数据库权限层直接拒绝写操作。实测 20 条攻击用例 0 逃逸。"

## 第二幕 · 高危操作审批 + 群通知（2:30–4:30）≈ 2min

> **画面**：对话页切 ops 会话 / 或直接切审批页

操作：
1. 对话页输入"**把订单 PO-0002 的金额改成 9500**" → 出现 `approval_request` 事件提示（before/after diff）
2. 口播："高危写操作不会直接执行——先弹审批单，before/after 对比，等人工确认。这就是 HITL（Human-in-the-loop）审批门。"
3. 切到**审批页**（Tab 2）→ 待审列表 → 选中该单 → 填理由 → 通过
4. 口播："同时这个审批请求会推送到 IM 群机器人——摘要卡片只带审批 id 和变更字段名，**不带敏感金额**；webhook 挂了审批照常，只是没通知（通知尽力而为）。"
5. 切回对话页看到执行完成（口播："批准后 LangGraph 断点自动续跑，订单状态更新"）

**金句**："改单 100% 走审批 + 100% 审计；同一条操作重复点不会重复执行——幂等键；下游挂了有熔断器兜底；Redis 挂了写路径 fail-closed 直接拒绝——安全叙事一致性。"

## 面试追问预案（demo 后可能被问）

- **为什么不直接用 Dify/Coze？** → 决策记录《06》：harness 自研能力 + 定制安全闸（四道闸）+ 成本控制（mock-first ¥20 vs 平台订阅）
- **数据量涨 100 倍哪里先崩？** → 单库写入瓶颈（ADR-010 拆库信号）→ Qdrant 分片（ADR-009 三级演进，已落地 L2）
- **40 并发为什么没到 1.5s？** → 如实说：净环境复验 1872~2095ms，归因本机 12 核 VM 吞吐天花板；正式口径 30 并发 714ms 稳达；数字真实、归因链完整
- **语义缓存错答怎么兜底？** → 相似度阈值 + 关键词校验双闸门 + 反馈纠错失效缓存 + 夜间评测抽样看偏离
- **MCP 高危工具为什么不暴露？** → 写操作必须走平台 REST + approval_gate（HITL），MCP 调用方无法绕过审批流——安全叙事一致性
- **自研 Runtime 值不值？** → ADR-011：data 图单轮无状态是"框架税>收益"场景；ops/kb 有 interrupt/checkpointer 生态留 LangGraph；"随时能退出"是解药
- **四道闸只是校验，模型绕过怎么办？** → 纵深防御：只读账号 DB 权限层兜底（ERROR 1142 实测），双层防线
