## 项目经历

### SCM Copilot · 供应链智能运营平台（独立完成，2026-08 → 09，6 周）

> **定位**：一站式供应链智能助手——问知识（RAG）· 查数据（NL2SQL）· 办业务（工具+审批）。由两个独立 Agent 应用演进为模块化单体生产平台：统一账号/审计/调度/监控，双实例无状态水平扩展，开放 pip SDK。
> **终验**：18 项验收指标 17 项达成 + 1 项如实标注；pytest 344 项全绿；40 并发成功率 100%；真实 LLM 总成本约 ¥20。

#### 1. 平台化整合与无状态水平扩展（stage3 双项目 → 生产平台）

- 将知识问答（RAG）与业务操作（审批/幂等/熔断）两个独立应用整合为模块化单体，域按 API 边界隔离（kb/ops/data/platform/scheduler），**68 项回归全绿**（原 109 项同语义折算）+ ruff/mypy 0 error。
- 数据从 SQLite 迁移至 MySQL 8 权威库：4 类数据（feedback 13 / audit 19 / checkpoints 358 断点 + 858 写入）**行数 + 校验和全一致**，幂等脚本连跑 3 遍结果不变；RBAC 三级权限（4 角色 × 12 权限码）+ JWT 双令牌统一账号体系。
- **全状态外置核销**：checkpointer/审批/会话 → MySQL，幂等/缓存/锁 → Redis，身份用无状态 JWT —— 由此将 ip_hash 粘滞路由改为 **least_conn 真无状态水平扩展**。
- **结果**：双实例 30 并发正式基线 **210/210 = 100%、P95 1.3s、5xx=0**；40 并发极限成功率 100%（P95 如实记录）；压测中段杀掉一个实例 **210/210 请求不中断、5xx=0**，容器重启数据零丢失。

> **翻车细节（面试主动讲）**：原方案 ip_hash 会话亲和，同一 IP 长连接把流量压在一个实例上；换 least_conn 的前提不是改配置，而是**把 8 项进程内状态全部外置核销**——状态外置清单逐项打勾后路由策略才有资格换。

#### 2. NL2SQL 数据分析域（从零建设，安全纵深）

- 自然语言查询业务库（六表万级固定种子，orders 1 万 / items 3.5 万），生成链路：问题 → Schema Linking（表列召回注入）→ LLM → 校验 → 只读沙箱 → 表格 + SQL 透出 + 洞察摘要。
- **安全纵深两层防御**：sqlglot AST 四道闸（单语句/仅 SELECT/子句级禁写/危险函数黑名单，确定性校验）→ 数据库 `nl2sql_ro` 只读账号兜底（ERROR 1142 实测）——即使校验有未知绕过，权限层也写不进。
- **结果**：execution accuracy（结果集比对，非 SQL 字符串比对）real 100 条**整体 0.97**（单表 0.98 / join 0.95 / 聚合 1.0）；**20 条攻击用例 0 逃逸**（堆叠/伪装嵌写/危险函数/FOR UPDATE）；real P95 39ms；错误自修复救回 0.93、多轮追问 9/10；SQL 100% 透出可审计可纠错。

> **翻车细节（面试主动讲）**：最初想用 SQL 字符串比对做评测，发现同义 SQL（LEFT JOIN vs 子查询、列序不同）大量误判；改为**结果集规范化比对**（类型归一 + 排序键整行）后才真正反映"答对数据"。

#### 3. 调度域与数据闭环自动化（六任务，多实例零重复）

- APScheduler 六任务（KB 增量同步 /5min、向量清理、审计归档、日报 /1-5 08:00、夜间评测 /2:00、缓存预热 /7:00）+ MySQL job store（任务定义重启不丢）+ Redis leader 锁。
- **零重复三层分治**：调度器全实例跑（高可用）→ leader 锁互斥（`SETNX NX EX` + owner 校验）→ 任务幂等键兜底（日期键/内容寻址，锁失效时重复执行=执行一次）。
- **结果**：双实例稳态 **30/30 窗口零重复**（job_runs 表逐窗口证据）；改文档 **≤5min** 即可检索；日报自动生成数字可回溯 SQL（GMV 3674 万 / 延迟率 9.9%）；夜间评测自动回归，质量劣化次日可见。

> **翻车细节（面试主动讲）**：24h 观测中出现 2 个异常窗口（06:00 双 skipped / 06:15 双 success）——逐条查根因发现是测试残留实例持锁 + 部署重建窗口，非生产行为；**"零重复"的证据是在异常排查之后才敢说的**。

#### 4. 开放能力与可观测性

- pip 安装 SDK（`scm-copilot-client`）10 行接入三接口（chat_stream / nl2sql / approvals），**13/13 测试通过**（含真实 HTTPS 平台集成）；OpenAPI 3.1 + Swagger **端点覆盖 100%**；API Key + 令牌桶配额（超限 **429 + Retry-After** 实测）。
- Prometheus + Grafana 业务五区面板（NL2SQL 质量趋势 / 语义缓存命中 / 队列与调度 / 流量健康 / 成本看板）有真实数据流动；故障演练五连（杀 MySQL/Redis/Qdrant/LLM 全超时/实例）**5/5 自动降级不雪崩**，恢复自动回归。
- **质量与成本**：pytest **344 passed**、ruff/mypy 0 error、RBAC 越权 12 组全过、写操作 100% 审批 + 100% 审计；mock-first 开发纪律，月真实 LLM 成本 **约 ¥20**（预算 ¥100 内）。

> **翻车细节（面试主动讲）**：故障演练暴露认证层在 MySQL 挂时全局 500——当天改为 JWT 签名本地校验 + 存储 fail-open（篡改仍 401，DB 故障不拖垮全部请求），**修复 + 新增 5 个测试 + 镜像重建全闭环**。
