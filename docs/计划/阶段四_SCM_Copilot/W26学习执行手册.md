## 五、本周六问（Day1 快答 + Day7 复盘）

1. **规模**：压测 20/40 并发阶梯 × 200 请求；验收 40+ 项；录屏 10 分钟
2. **失败路径**：演练本身就是失败路径测试——每个故障的降级行为见 Day2 表
3. **权限**：Grafana 面板截图脱敏（演示数据无真实 PII）；README 不泄 API Key
4. **成本**：录屏 + 日报演示 real 各一次（预算余量 ~¥10）；其余全 mock
5. **部署**：一键全家桶 = mysql + redis + qdrant + backend×2 + nginx + prometheus + grafana + node-exporter + cadvisor（10 容器）
6. **数据闭环**：验收数字回填简历 → 投递 → 每场面试反馈回流话术库（闭环到求职本身）

## 六、七天计划

### Day1（9/7 周一）★ 业务监控面板

**目标**：五个业务面板全部有真实流动数据——面试演示时"指曲线讲故事"。

**上午**：
1. `scm_business.json` 面板五区：
   - **NL2SQL 质量**：eval_nightly 分数趋势（eval_reports 表 → MySQL datasource 或 exporter 暴露 metric）、分层准确率、拒答率
   - **语义缓存**：命中率 / 命中 P95 vs 未命中 P95（W22 已有指标接上）
   - **队列与调度**：RQ 队列深度 / 六任务 24h 成功率 / 上次运行距今
   - **流量健康**：QPS / P95 / 错误率（按域分标签 kb/ops/data）
   - **成本看板**：token 用量按模型 / 单轮成本 / 日预算水位
2. 自定义 metrics 补齐：`scm_nl2sql_eval_score`（Gauge，夜间任务更新）/ `scm_job_success_total`（Counter，label=job）

**下午**：
3. 面板验证：跑一轮压测 + 手动触发 eval → 五区曲线实时动（Grafana 时间范围 15min 刷新 5s）
4. 面板截图归档进 `reports/`（验收证据）；两个面板导出 JSON 进仓
5. 欠账清偿窗口：W25 遗留尾工（上限 2h，超出记 backlog 不进本周）

**面试题 0.5h**：监控三支柱（logs/metrics/traces）在你平台的分工——Prometheus 看趋势、LangFuse 看单次链路、JSON 日志做取证。

**验收**：五区面板有真实数据流动；自定义 metric 可查；截图归档。
**坑**：
- MySQL datasource 直连查 eval_reports 最简单（Grafana MySQL 插件），别为了一致性硬上 exporter
- 面板查询时间窗口对齐任务周期（夜间任务的数据要看 24h 窗口）
- `label` 基数控制：job label 只有 6 个值，别把 trace_id 之类塞进 label

### Day2（9/8 周二）★ 故障演练五连

**目标**：杀穿全家桶，验证降级链五连不雪崩——"敢上线"的实证日。

**上午（演练三连）**：
1. 准备：`deploy/chaos/` 五个脚本（`docker stop mysql` / `stop redis` / `stop qdrant` / 停 LLM key 注入超时 / `stop backend-a1`）+ 观察脚本（持续 curl 探活 + Grafana 截屏）
2. **杀 MySQL**：预期——健康检查摘除 backend？不对：backend 连不上库时自身降级——审批暂停（返回 503 明确提示）、chat 缓存路径可用、写操作全拒不雪崩；恢复后 HITL 断点续跑
3. **杀 Redis**：预期——fail-open 降 SQLite（幂等/缓存/锁全走降级路径，响应变慢但可用）；恢复后自动切回（验证无缝）

**下午（演练两连 + 修复）**：
4. **杀 Qdrant**：预期——检索降级 BM25-only（召回降级标记进响应/日志）；恢复后混合检索自动回
5. **LLM 全超时**（改 provider 配置全指向失效 key + 短超时）：预期——模型池三级切换 glm→kimi→qwen 全失败 → mock 兜底话术（明确告知降级）；usage 记账不重复
6. **实例半瘫**：压测中 `stop backend-a1`：预期——least_conn 摘除、5xx=0、流量集中 a2（Grafana 曲线可见）；恢复后自动回来
7. 当天修复演练暴露的问题（预案外行为逐条修或记 ADR 修订）；`chaos_drill.md` 五连记录（故障/预期/实际/修复/截图）

**面试题 0.5h**：完整口述"故障演练五连"故事——每个故障的降级链是 W19–W22 铺的，今天全部兑现（最强的"纵深防御"叙事素材）。

**验收**：5/5 场景自动降级不雪崩；恢复自动回归；记录完整。
**坑**：
- 演练顺序从轻到重（Qdrant→Redis→MySQL），出问题好定位
- "不雪崩"的判定标准先写下来：探活 5xx < 5%、无级联超时、恢复 <2min 自动回归
- LLM 超时演练记得把 provider 配置改回来（别带着故障配置跑周三验收）
