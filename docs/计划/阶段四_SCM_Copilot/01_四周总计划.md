## 二、项目定位（一句话 + 边界）

**SCM Copilot 供应链智能运营平台**：把 stage3-project-a（知识问答）与 stage3-project-b（业务操作）整合为模块化单体生产平台，用户在一个入口完成**问知识（RAG）、查数据（NL2SQL）、办业务（工具+审批）**，统一账号、审计、调度、监控与开放 SDK，双实例无状态可水平扩展。

**净新增四件套**（补齐差距清单最后空白）：MySQL + NL2SQL ｜ APScheduler 调度域 ｜ SDK + Swagger 开放能力 ｜ 真无状态多实例（least_conn）
**三个吸收项**（均 ≤2 天）：Hooks 中间件 ｜ node-exporter/cAdvisor 基础监控 ｜ mkcert 本地 TLS

**非目标**（沿用 08-15 决策，写入 README，完整清单见《06》第 5 节）：等保正式化、OCR/Whisper、钉钉企微 IM、LoRA、多 GPU、BI 图表引擎、桌面客户端、行业多场景定制。

架构图、DDL、API 清单见《[02 架构设计与数据模型](02_架构设计与数据模型.md)》。

## 七、ADR 速览（8 条，详版见《[04 ADR与风险应对](04_ADR与风险应对.md)》）

1. **模块化单体**而非微服务——域间强关联、单机约束；域按 API 边界隔离，可演进拆分
2. **MySQL 8** 权威库——并发写/行锁；SQLite 保留为 Redis 故障 fail-open 降级
3. **保留 Qdrant+BM25**——W5 压测达标（432 QPS/P95 27ms），运维轻；数据量千万级再评估 Milvus
4. **ip_hash→least_conn**——前提：状态全外置（W23-D6 核销清单）
5. **APScheduler+Redis 锁**而非 Celery beat——已有 RQ，beat 引入新 broker 语义不值
6. **checkpointer=AsyncMySQLSaver**——复用主库，HITL 断点与业务库同源
7. **sqlglot AST 校验**而非正则——确定性解析无逃逸；配只读账号双保险
8. **SDK 薄封装 httpx**而非代码生成——三接口手写更可控；端点增后再切生成
